# Афиша концертов — бэкенд MVP

Афиша описывает концерт и связана с одной или несколькими
[площадками](venue.md). Сначала создайте площадку, затем передайте её `id` в
`venue_ids` при создании афиши. [Изображения](img.md) можно загрузить сразу
или добавить позже.

## Подключение

- Запуск — по [README](../README.md): `make up` создаёт контейнеры и применяет миграции.
- Базовый адрес при стандартном запуске — `http://localhost:8080`; интерактивная схема — `/docs`.
- Изменяющие ручки афиши **сейчас не проверяют роль**: зависимость
  `require_admin` в них закомментирована. Не считайте их защищёнными до
  включения авторизации.

## API афиши

| Запрос | Назначение | Ответ |
| --- | --- | --- |
| `POST /api/afisha` | Создать афишу и при необходимости загрузить изображения | `201`, афиша с `images` |
| `GET /api/afisha` | Список, поиск и пагинация | `200`, `items`, `total`, `page`, `page_size` |
| `GET /api/afisha/{afisha_id}` | Получить афишу с изображениями | `200`, афиша |
| `PUT /api/afisha/{afisha_id}` | Полностью обновить данные, не меняя изображения | `200`, афиша |
| `PATCH /api/afisha/{afisha_id}` | Обновить переданные поля | `200`, афиша |
| `DELETE /api/afisha/{afisha_id}` | Удалить афишу и её изображения | `204`, без тела |

Обязательные поля афиши: `title`, `starts_at`, `ends_at`, `venue_ids` (непустой
массив UUID существующих площадок). `ends_at` должен быть позже `starts_at`.
Необязательные поля: `short_description`, `description`, `age_limit`
(`0`, `6`, `12`, `16` или `18`) и `status` (`published` по умолчанию либо
`cancelled`). Даты передавайте в ISO 8601 с часовым поясом.

POST принимает `multipart/form-data`: поле `afisha` — **текстовая JSON-строка**,
а `images` — необязательные файлы. Для нескольких изображений повторите поле
`images`. В Swagger UI вставьте JSON в поле `afisha` и выберите файлы в `images`.

```sh
curl -X POST http://localhost:8080/api/afisha \
  -F 'afisha={"title":"Музыкальный понедельник","starts_at":"2026-11-02T19:00:00+03:00","ends_at":"2026-11-02T21:00:00+03:00","venue_ids":["11111111-1111-4111-8111-111111111111"],"age_limit":12}' \
  -F 'images=@./poster.jpg' \
  -F 'images=@./hall.png'
```

Замените UUID на `id` созданной [площадки](venue.md), а пути — на свои файлы. PUT и PATCH,
в отличие от POST, принимают обычный `application/json` без файлов. PATCH не
умеет очищать необязательное поле передачей `null`: сейчас `null` означает
«не изменять».

Ответ GET по ID и ответы на создание/обновление содержат `id`, поля афиши,
`venue_ids`, `created_at`, `updated_at` и массив `images`:

```json
{
  "id": "22222222-2222-4222-8222-222222222222",
  "title": "Музыкальный понедельник",
  "short_description": null,
  "description": null,
  "starts_at": "2026-11-02T19:00:00+03:00",
  "ends_at": "2026-11-02T21:00:00+03:00",
  "venue_ids": ["11111111-1111-4111-8111-111111111111"],
  "age_limit": 12,
  "status": "published",
  "images": [{"id":"33333333-3333-4333-8333-333333333333","image_url":"/uploads/4a5b6c7d8e9f00112233445566778899.jpg","is_cover":true,"position":0}],
  "created_at": "2026-10-15T12:00:00Z",
  "updated_at": "2026-10-15T12:00:01Z"
}
```

В списке афиш вместо массива изображений возвращаются `cover_url` и
`venue_names`. `page` по умолчанию равен 1, `page_size` — 20 (максимум 100);
`search` ищет афиши по названию и описаниям. Выдача файлов и смена обложки
описаны в [документе об изображениях](img.md).

## Ошибки и хранение

| Код | Причина |
| --- | --- |
| `400` | Неверные данные афиши или неподдерживаемый формат загружаемого изображения |
| `404` | Афиша или указанная площадка не найдена |
| `422` | Некорректный UUID, JSON или обязательное поле запроса |

Данные афиш и связей с площадками хранятся в PostgreSQL. Афишу с сообщениями
обсуждения физически удалить нельзя: внешний ключ сообщений запрещает это.
О хранении файлов см. [документ об изображениях](img.md).
