# Площадки концертов — бэкенд MVP

Площадка хранит название, город, адрес и необязательные координаты. При
создании [афиши](afisha.md) передайте `id` одной или нескольких площадок в
`venue_ids`.

## Подключение

- Запуск — по [README](../README.md): `make up` создаёт контейнеры и применяет миграции.
- Базовый адрес — `http://localhost:8080`, интерактивная схема — `/docs`.
- Изменяющие ручки площадок **сейчас не проверяют роль**: зависимость
  `require_admin` закомментирована.

## API

| Запрос | Назначение | Ответ |
| --- | --- | --- |
| `POST /api/venues` | Создать площадку | `201`, площадка с `id` |
| `GET /api/venues` | Список, поиск и пагинация | `200`, `items`, `total`, `page`, `page_size` |
| `GET /api/venues/{venue_id}` | Получить площадку | `200`, площадка |
| `PUT /api/venues/{venue_id}` | Полностью обновить площадку | `200`, площадка |
| `PATCH /api/venues/{venue_id}` | Обновить переданные поля | `200`, площадка |
| `DELETE /api/venues/{venue_id}` | Удалить площадку | `204`, без тела |

POST и PUT принимают JSON с обязательными `name`, `city`, `address`.
Необязательные `latitude` и `longitude` ограничены диапазонами −90…90 и
−180…180. PATCH принимает те же поля, но все они необязательны; передача
`null` сейчас не очищает координаты.

```http
POST /api/venues
Content-Type: application/json

{"name":"Георгиевский зал","city":"Москва","address":"Тверская улица, 1"}
```

Ответ площадки:

```json
{
  "id": "11111111-1111-4111-8111-111111111111",
  "name": "Георгиевский зал",
  "city": "Москва",
  "address": "Тверская улица, 1",
  "latitude": null,
  "longitude": null
}
```

`GET /api/venues` поддерживает `page` (по умолчанию 1), `page_size`
(по умолчанию 20, максимум 100) и `search` по названию, городу и адресу.

## Ошибки и хранение

| Код | Причина |
| --- | --- |
| `400` | Название, город или адрес состоят только из пробелов |
| `404` | Площадка не найдена |
| `422` | Некорректный UUID, тело запроса или координаты вне допустимого диапазона |

Площадки хранятся в PostgreSQL. Удаление площадки, связанной с афишей,
удаляет эту связь; не удаляйте последнюю площадку афиши, пока не назначите
ей другую.
